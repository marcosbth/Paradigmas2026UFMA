# 🎓 Paradigmas de Programação

Repositório destinado ao armazenamento de códigos, notas de aula, projetos e laboratórios práticos desenvolvidos durante a disciplina de **Paradigmas de Programação** do curso de Bacharelado ciencia e recnologia na Universidade Federal Maranhao.

---

## 📌 Visão Geral da Disciplina

A cadeira aborda os principais modelos conceituais que estruturam as linguagens de programação. O objetivo é compreender como diferentes paradigmas influenciam a resolução de problemas, o design de software, a expressividade e a eficiência do código.

---

## 💻 Paradigmas Explorados & Linguagens

O repositório está dividido com base nos paradigmas estudados e nas tecnologias utilizadas na disciplina:

* **Paradigma Funcional**
  * Foco em imutabilidade, funções de alta ordem, avaliação preguiçosa (*lazy evaluation*) e recursão.
  * **Linguagens:** `Haskell` / `Clojure` / `OCaml` *(Mantenha apenas as que usou)*
* **Paradigma Imperativo**
  * Resolução de problemas baseada em comandos e seleção que alteram estado da memoria.
  * **Linguagens:** C, Python
* **Paradigma Orientado a Objetos (POO)**
  * Aplicação profunda de pilares como encapsulamento, herança, polimorfismo e abstração.
  * **Linguagens:** `Java` / `C++` *(Mantenha apenas as que usou)*
* **Paradigma Declarativo**
  * Gerenciamento de threads, exclusão mútua, semáforos e modelo de atores.
  * **Linguagens:** `Go` / `Erlang` / `Java` *(Mantenha apenas as que usou)*

## 🚀 Como Executar os Códigos

### ⚡ Pré-requisitos
Para rodar os projetos deste repositório, você precisará dos seguintes compiladores/interpretadores instalados:
* GHC (para Haskell)
* MinGW/VsCode/CodeBlocks (para C)
* JDK 17+ (para Java)

### 🏃 Exemplo: Rodando um script em Haskell
1. Navegue até a pasta do paradigma:
   ```bash
   cd paradigma-funcional
   ```
2. Abra o interpretador interativo carregando o arquivo:
   ```bash
   ghci main.hs
   ```
